## US05: ลานใกล้ที่สุดและนำทาง

| ID | กรณีทดสอบ | ขั้นตอน | ผลที่คาดหวัง | ผล (ผ่าน/ไม่ผ่าน) |
|----|-----------|---------|--------------|-------------------|
| UAT-08 | หาลานใกล้ที่สุดสำเร็จ | เลือกประเภทรถ กดปุ่มหาลานใกล้ฉัน แล้วอนุญาตตำแหน่ง | ขึ้น "กำลังหาตำแหน่งของคุณ..." แล้วแสดงการ์ดผล (รหัส · ชื่อลาน · ระยะห่างโดยประมาณเป็นเมตร) | |
| UAT-09 | ไม่แสดงจำนวนที่ว่าง | ดูการ์ดผลจาก UAT-08 | ไม่มีข้อความจำนวนที่ว่างในการ์ด | |
| UAT-10 | ปุ่มนำทาง | กดปุ่มแดง "นำทาง (เปิด Google Maps)" | เปิดแท็บใหม่ไป Google Maps โดยปลายทางคือลานที่แสดง | |
| UAT-11 | เส้นประบนแผนที่ | ดูแผนที่หลัง UAT-08 | มีจุดตำแหน่งผู้ใช้ และเส้นประไปยังลานที่ใกล้ที่สุด แผนที่ซูมให้เห็นทั้งสองจุด | |
| UAT-12 | เปลี่ยนประเภทรถ | เปลี่ยนประเภทรถ แล้วกดหาลานใกล้ฉันอีกครั้ง | ผลค้นหาใหม่ตามประเภทรถที่เลือก เส้นประเดิมถูกลบ ไม่ซ้อนกัน | |
| UAT-13 | ไม่อนุญาตตำแหน่ง | กดหาลานใกล้ฉัน แล้วกดไม่อนุญาตตำแหน่ง | ขึ้นกล่องแดงแจ้งใช้ตำแหน่งไม่ได้ และทุกลานมีปุ่ม "นำทาง" | |
| UAT-14 | ทุกลานของประเภทรถนี้เต็ม | เลือกประเภทรถที่ทุกลานเต็ม (ใช้ข้อมูลทดสอบ) แล้วกดหาลานใกล้ฉัน | ขึ้นกล่องแดงพร้อมข้อความไทยจาก API และมีปุ่ม "นำทาง" ของทุกลาน | |
| UAT-15 | ตำแหน่งหมดเวลา / เบราว์เซอร์ไม่รองรับ | ปิด GPS ให้รอเกิน 10 วินาที หรือทดสอบบนเบราว์เซอร์ที่ไม่รองรับ | ขึ้นกล่องแดงแจ้งข้อผิดพลาด และทุกลานมีปุ่ม "นำทาง" ไม่ค้างที่ข้อความกำลังหา | |
